# Projetos em Destaque

## Automação de Busca de Veículos com IA

Automação desenvolvida com **n8n** para realizar buscas de veículos a partir de critérios definidos pelo usuário.

O workflow consulta uma base de dados, filtra os veículos encontrados e utiliza **Inteligência Artificial (Google Gemini)** para gerar automaticamente um e-mail comercial personalizado com as informações dos veículos.

**Tecnologias**

- n8n
- Google Gemini
- Google Sheets
- APIs
- IA Generativa
- Automação de e-mail

---

## Automação de Controle de Estoque

Workflow desenvolvido com **n8n** para automatizar o monitoramento de estoque.

O sistema verifica diariamente os produtos que estão abaixo do estoque mínimo e envia automaticamente um relatório por e-mail contendo os produtos que precisam de reposição.

**Tecnologias**

- n8n
- Google Sheets
- Automação de e-mail
- Excel
- Workflows

---

## Sistema Inteligente de Monitoramento Hídrico

Projeto IoT desenvolvido utilizando **ESP32** para monitoramento do nível de reservatórios e controle automático de bomba d'água.

O sistema realiza a leitura do nível da água e utiliza regras de automação para controlar o acionamento da bomba.

**Tecnologias**

- ESP32
- C++
- Sensores
- HTTP
- IoT
- Automação

---

## GASTRACK

Sistema IoT para monitoramento remoto de botijões de gás utilizando ESP32, sensores e dashboard web.

O projeto tem como objetivo acompanhar remotamente informações relacionadas ao nível do gás e disponibilizar os dados para monitoramento.

**Tecnologias**

- ESP32
- Firebase
- MQTT
- HTML
- CSS
- JavaScript

---

## Sistema de Telemetria MQTT

Implementação de uma arquitetura **Publish/Subscribe** para comunicação entre dispositivos IoT e aplicações.

O projeto utiliza MQTT para transmissão de dados entre dispositivos embarcados e uma aplicação Python responsável pelo processamento das informações.

**Tecnologias**

- ESP32
- MQTT
- Python
- MySQL
- IoT
